# Navoyage Frontend

The Navoyage wordmark, page title, runtime configuration, app icon, and favicon use the orange brand palette. Logo files are in `src/Assets/Images/NavoyageLogo.png` and `src/Assets/Images/NavoyageWCLogo.png`; browser icons are in `src/Assets/Icons`.

The logo was generated with the built-in image-generation tool using this prompt:

> Use case: logo-brand. Asset type: production web application app icon and favicon for the travel booking brand Navoyage. Create ONE beautifully finished flat vector-style symbol only, no text, no wordmark. Transparent background with actual alpha. A strong compact uppercase N monogram formed from a continuous navigation route, with a small compass/forward arrow incorporated naturally into its upper right stroke. Simple bold silhouette, legible at 32px. Primary colour warm EndaVay-style orange #f97316 with burnt orange #ea580c for subtle two-tone distinction. The new brand is Navoyage, so no E or V monogram. No green, teal, blue, black background, gradients, mockups, shadows, circles with tiny travel clipart, or decoration. Center one mark with modest 8 percent padding on a square canvas. Keep strokes clean, refined, balanced, professional.

To start a local development server, run:

```bash

```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
